# 打卡记忆卡（开源合集）

一个「打卡 + 间隔重复记忆卡」工具的完整源码，含三套实现：

| 目录 | 说明 | 状态 |
|---|---|---|
| `打卡记忆卡-网页版/` | 纯网页离线版：浏览器打开即用，支持 Anki CSV / `.apkg` 导入，无后端、数据存 localStorage、断网可用。当前主线版本。 | 可用 |
| `打卡记忆卡-云函数代码骨架/` | 微信小程序云开发版：4 个云函数 + 完整前端工程 + 上线指南。 | 已放弃，仅保留骨架 |
| `打卡记忆卡小程序-实现要点.md` | 小程序版的实现要点笔记（Anki 包解析、SM-2 等）。 | 笔记 |

## 网页版怎么跑

见 [`打卡记忆卡-网页版/README.md`](打卡记忆卡-网页版/README.md)。把该目录整体托管到任意静态站点（GitHub Pages / Vercel / Netlify / 腾讯云 COS 等）即可，手机浏览器打开链接，装到主屏就是 PWA。

> 分享用的二维码 PNG（原部署产物，绑定某个 `?sharecode=` 分享链接）不属于源码，未纳入本仓库。需要时可按 `打卡记忆卡-网页版/tests/make_qr.py` 自行生成。
